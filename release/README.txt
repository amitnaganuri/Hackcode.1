====================================================
  UltimateFocus  v1.0
  Block the feed, keep the app.
====================================================

  File to install:  UltimateFocus-v1.0.apk


----------------------------------------------------
  STEP 1  -  INSTALL
----------------------------------------------------

  1. Copy UltimateFocus-v1.0.apk to your Android phone.
  2. Open the file on the phone.
  3. Android may say it cannot install from this source.
     Tap "Settings", turn on "Allow from this source",
     then press back.
  4. Tap "Install".
  5. Tap "Open".

  Works on Android 7.0 and newer, on any phone.
  One file, no "wrong version for my phone".


----------------------------------------------------
  STEP 2  -  GIVE ONE PERMISSION
----------------------------------------------------

  The app opens on a screen asking for permission.
  This is needed. Without it the app cannot see which
  app you opened, so it can never block anything.

  1. Tap "Open Accessibility settings".
  2. Tap "Downloaded apps".
  3. Tap "UltimateFocus".
  4. Turn the switch ON.
  5. Tap "Allow".
  6. Press back twice.

  The app opens by itself and will not ask again.

  The other item, "Usage Access", is OPTIONAL.
  You can skip it.


----------------------------------------------------
  STEP 3  -  TRY IT (2 MINUTES)
----------------------------------------------------

  1. Open "Blocks", tap "+ Add New Block Rule".
  2. Choose "Block Shorts / Reels".
  3. Search for YouTube and select it.
  4. Tick "Shorts", then tap "Save Rule".
  5. Open YouTube. It opens normally.
  6. Tap the "Shorts" tab.
       -> UltimateFocus stops you with a pause screen.
  7. Press back.
       -> You land on YouTube's home page,
          not back inside Shorts.
  8. Open "Insights" to see the block counted.


----------------------------------------------------
  WHAT IT CAN DO
----------------------------------------------------

  - Block a whole app.
  - Block only one part of an app: Shorts, Reels,
    Stories, Explore, For You. The rest still works.
  - Daily time limits, any length you choose.
  - "Teach this screen": if a screen is not
    recognised, show it to the app once and it
    learns it on your phone.
  - Focus sessions with a timer that stays correct
    even if the phone sleeps.
  - Strict Mode: rules lock while a session runs.
  - Insights: focus time, screen time, blocks
    stopped, streak, and a 7 day chart.


----------------------------------------------------
  IF SOMETHING DOES NOT WORK
----------------------------------------------------

  Nothing is blocked
     The permission is off. Go to phone Settings ->
     Accessibility -> Downloaded apps ->
     UltimateFocus -> turn it on.

  It stopped working after reinstalling
     Android removes this permission when an app is
     reinstalled or force stopped. Turn it on again.

  Reels or Stories are not blocked
     Open that rule and use "Teach this screen".
     Open the app on a different screen first, then
     go to the one you want blocked. It needs to see
     you move between two screens.

  All numbers are zero
     It is a fresh install. They fill up as you use
     the app. Nothing here is fake data.


----------------------------------------------------
  HONEST NOTES
----------------------------------------------------

  - YouTube Shorts blocking is tested and working.
    Instagram, Snapchat, TikTok, Facebook, X and
    Reddit are best effort, because those apps
    rename their screens between updates.
    "Teach this screen" fixes any of them in about
    twenty seconds.

  - If a screen is not recognised, the app stays
    usable. It will never block a whole app by
    mistake.

  - "Recovered time" is an estimate: 3 minutes for
    each block stopped. No app can measure the
    scrolling that never happened.
